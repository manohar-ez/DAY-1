Day 2: The Core Trio of the Web – HTML, CSS, and JavaScript
Today marks the second day of my web development journey, and it has been an incredibly hands-on and productive experience. My primary focus was on understanding how the three foundational technologies of the web—HTML, CSS, and JavaScript—interact to create a cohesive, functional, and visually appealing web application. Coming out of today’s session, I have a much clearer picture of how a website transitions from a basic structural skeleton to a fully interactive user experience.

Structuring with HTML
I began by diving into HTML (HyperText Markup Language), which serves as the fundamental architecture of any webpage. I learned about the importance of various core tags and how they give meaning and hierarchy to web content. Specifically, I worked with heading tags, utilizing the <h1> tag to define the most important structural titles on the page, alongside other basic elements to organize my layout. Additionally, I learned how to properly use HTML comments (<!-- comment -->). Understanding how to comment out code and leave documentation is a crucial takeaway, as it allows me to leave helpful notes for myself and other developers in the source code without affecting the live rendering of the page.

Designing with CSS
Once the raw structure was in place, I transitioned into CSS (Cascading Style Sheets) to breathe life into the document. I learned how CSS acts as the presentation layer, allowing me to design, format, and style the previously plain HTML elements. I explored how to target specific HTML tags and apply visual rules to them, manipulating properties to change how the page looks to the end-user. Seeing the page transform from a sterile document into a customized, designed interface really solidified my understanding of how CSS controls the aesthetic identity of a project.

Adding Interactivity with JavaScript
The most exciting part of Day 2 was introducing JavaScript. I learned how JavaScript operates in the background to handle the core logic and behavior of a website. While HTML and CSS are largely static, JavaScript is dynamic—it listens for user actions and updates the page in real-time.

The main highlight of my practical session today was implementing a functional toggle button. By writing custom background logic, I was able to connect JavaScript event listeners to my HTML elements and CSS classes. This allowed the button to dynamically switch states on the screen when clicked, proving exactly how JavaScript drives user interactivity behind the scenes.

Reflection
Overall, today bridged the gap between structure, style, and logic. Building a dynamic toggle feature from scratch taught me exactly how these three languages communicate with one another. I am excited to continue expanding on these basics and applying them to more complex interactive projects in the coming days.
