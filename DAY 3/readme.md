Day 3: API Testing, SQL Design & Git Workflows
=> Overview
Today was hands-on with backend concepts, database structure, and modern development tools. The sessions covered API fundamentals, interactive testing, SQL schema creation, and Git version control.

=> Key Learnings & Practical Exercises
1. APIs & Authentication
API Keys: Explored how API keys act as secure access tokens to authenticate client requests and manage permissions.

HTTP Methods:

GET: Learned how to fetch and retrieve data from a remote server without modifying it.

POST: Practiced sending payload data to a server to create new resources or process information.

2. Hands-on API Testing with Postman
Environment Setup: Configured Postman to send structured HTTP requests.

Request & Response Flow: Tested GET and POST endpoints, examined status codes (e.g., 200 OK, 201 Created), and verified returned JSON response bodies.

3. Database Schema Design (SQL)
Designed a 3-table college database schema (students, departments, courses).

Implemented primary keys, foreign keys, and basic data constraints.

Executed data manipulation queries and utilized aggregate functions (COUNT, AVG, MAX, MIN, SUM) along with GROUP BY clauses.

4. Interactive Learning & Team Collaboration
Participated in interactive learning activities and games designed to test quick recall on web protocols, database relations, and API operations.

=>Tools Used
Postman: API request building, header configuration, and response inspection.

SQL / SQLite: Database creation, querying, and aggregate data analysis.

Git & GitHub: Version control management, staging, committing, and remote repository synchronization.
